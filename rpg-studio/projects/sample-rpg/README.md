# サンプル「森境の小さな冒険」

旅人アオが、遺跡の石像の番人を鎮めて村へ戻る短いRPGです。最初に種族（小人／獣人／人間）を選びます。種族・技・店・ルールはすべてJSONのデータで、TypeScriptは「旅の日誌」の文章づくり（`systems/chronicle.ts`）だけです。

| 種族 | 補正 | 能力 |
| --- | --- | --- |
| 小人 | 最大HP+4・防御+1 | 不屈の魂（1戦闘1回、致命傷をHP1でこらえる）、大地の守り（気力2で回復） |
| 獣人 | 攻撃+1 | 獣道（岩の隙間を通れる）、野生の一撃（25%で2倍）、かみつき（気力2で攻撃×2） |
| 人間 | — | 応急手当（気力1で回復、いつでも）、商才（勝利時+2G）。開始時に薬草2・10G |

全体ルール（`rules.json`）: 魔物を倒すと2〜5G／8歩ごとに気力+1／3体倒すと攻撃+1（1回）／番人を倒して村に戻ると演出。

## 流れ

1. 苔森の村でリオ（獣人の斥候）に話しかけ、**獣道**を教わる（選択肢は一度だけ報酬）。獣人ならすでに知っていて、台詞が変わる。
2. 北の家の長老オババから薬草をもらえる（一度だけ）。休むとHPと気力が全回復。よろず棚（店）で薬草・お守りを買える。日誌で旅の記録を読める。
3. 橋を渡って東の風穴の遺跡へ。入口から石畳をまっすぐ進むと**岩の隙間**。獣道があれば調べて近道を開ける。無い場合は落ち葉の積もった回り道（魔物が出る）を通る。
4. 奥の**石像の番人**と戦う。3ターン周期で「力をためる」→「岩砕き」。ぼうぎょで半減。小人の**不屈の魂**は1戦闘に一度だけ致命傷をHP1でこらえる（2度目はない）。
5. 勝つと風の欠片。遺跡の大岩が消えて宝箱への近道ができる（地形の変化）。村へ戻って長老に報告すると完了（報酬は一度だけ）。

## どこに何があるか

| やりたいこと | ファイル |
| --- | --- |
| 開始位置・主人公の基本能力値・フラグと変数の宣言・種族選択（intro） | `project.json` |
| 種族（traits）・能力・技・アイテム・敵 | `database.json` |
| 全体ルール | `rules.json` |
| タイルの種類・通行条件（岩の隙間 `g` は `ruinsShortcutOpen` で通れる） | `tiles.json` |
| 地形・NPC・出入口・仕掛け・エンカウント | `maps/*.json` |
| セリフと選択肢 | `dialogues/dialogues.json` |
| 仕掛けの処理（条件・効果） | `events/events.json` |
| 旅の日誌（データで書きにくい文章づくり） | `systems/chronicle.ts` |
| 自動プレイテスト | `tests/*.scenario.json` |

獣道はタイルの `passableWhen` とイベントの `when: { ability }`、不屈の魂は `lethalDamage` ルール（`once: "battle"`, `modify.hp: 1`）だけで実現しています。
