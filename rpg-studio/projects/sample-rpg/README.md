# サンプル「森境の小さな冒険」

小人の旅人アオが、獣人の技「獣道」を教わり、遺跡の近道から石像の番人を鎮めて村へ戻る短いRPGです。

## 流れ

1. 苔森の村でリオ（獣人の斥候）に話しかけ、**獣道**を教わる（選択肢は一度だけ報酬）。
2. 北の家の長老オババから薬草をもらえる（一度だけ）。休むと全回復。
3. 橋を渡って東の風穴の遺跡へ。入口から石畳をまっすぐ進むと**岩の隙間**。獣道があれば調べて近道を開ける。無い場合は落ち葉の積もった回り道（魔物が出る）を通る。
4. 奥の**石像の番人**と戦う。3ターン周期で「力をためる」→「岩砕き」。ぼうぎょで半減。小人の**不屈の魂**は1戦闘に一度だけ致命傷をHP1でこらえる（2度目はない）。
5. 勝つと風の欠片。村へ戻って長老に報告すると完了（報酬は一度だけ）。

## どこに何があるか

| やりたいこと | ファイル |
| --- | --- |
| 開始位置・主人公の能力値・フラグの宣言 | `project.json` |
| タイルの種類・通行条件（岩の隙間 `g` は `ruinsShortcutOpen` で通れる） | `tiles.json` |
| 地形・NPC・出入口・仕掛け・エンカウント | `maps/*.json` |
| セリフと選択肢 | `dialogues/dialogues.json` |
| 仕掛けの処理（条件・効果） | `events/events.json` |
| 能力・アイテム・敵 | `database.json` |
| 不屈の魂（データで書けないルール） | `systems/abilities.ts` |
| 自動プレイテスト | `tests/*.scenario.json` |

獣道はコード不要で、タイルの `passableWhen` とイベントの `when: { ability }` だけで実現しています。
