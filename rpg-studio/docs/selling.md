# 作ったものを公開・販売する

RPGシステム工房で作ったゲームや素材は、作者のものです。公開も販売も自由です。工房は「売れる状態に仕上げる」ところまでを手伝い、お金のやりとりは販売サイト（itch.io・BOOTH など）に任せます。

## ゲームを売る

1. **販売前チェック** — 工房の「検証」画面の「販売前チェック」、または `pnpm rpg release-check --project projects/<id>`。次をまとめて確かめます。
   - データの検証・自動テスト・エンディングまで遊べる自動テストがあるか
   - 書きかけの文章（TODO・（仮）・〇〇 など）・文章の点検
   - **素材の権利**: そのゲームを売ってよいか（自作・内蔵ジェネレーター製は可。他サイトの素材は取得元と記録から判定）
   - クレジット表記がそろっているか
2. 「不可」があれば直します。「要確認」は、規約を読んだうえで `assets.json` のその素材に `"commercial": true`（売ってよい）か `false` を書きます。**AI生成の画像**は、使った生成サービスの規約で決まります。
3. ゲームを書き出します（ブラウザ版の工房なら「ゲームZIPを作る」、手元なら `pnpm rpg build --project … --zip`）。
   - **体験版**: 「検証」画面の「体験版」で、終わる所（このフラグが立ったら／このマップに入ったら）を決めると、完成版はそのままで体験版も書き出せます（ブラウザ版は「体験版ZIPを作る」、手元は `pnpm rpg build --project … --demo --zip`）。無料の体験版と有料の完全版、という売り方ができます
   - **作品ページの材料**: 「検証」画面の「作品ページの材料」で、カバー画像（630×500）・スクリーンショット・紹介文の下書き（日本語と短い英語）をまとめて作れます。紹介文は自分の言葉に直してください
4. 販売サイトにアップロードします。ブラウザで遊べるZIPは、itch.io なら「HTML」のゲームとしてそのまま有料（または投げ銭）で出せます。

### 更新しても、買った人のセーブが消えないように

売ったあとに直したり遊びを足したりすると、買った人の手元のセーブが新しい版で動かなくなることがあります。工房は次の2つで守ります。

- **読み込むときに合わせる**: 新しい版で古いセーブを読むと、あとから足したフラグ・変数・集合には初期値が入り、消した（名前を変えた）アイテム・技・特性・仲間・依頼・スキルボードのパネルの記録は外して読み込みます。セーブ自体は書き換えません。セーブ地点のマップを消すと読めないので、マップは消さずに残してください
- **出す前に確かめる**: `project.json` に `"version": "1.0.0"` のようにゲームの版を書き（工房の「販売前チェック」の「ゲームの版」欄でも）、公開する版で
  ```bash
  pnpm rpg release snapshot --project projects/<id>
  ```
  を実行します。自動テスト（`tests/*.scenario.json`）を通して遊び、セーブできる場面のセーブを `releases/1.0.0/saves/` に残します（テスト1つにつき最大4つ）。次に更新したときの `pnpm rpg release-check` が、それを今の版で読み込んで少し動かし、読めないセーブ（不可）や外した記録（注意）を知らせます。`releases/` は作品のフォルダーに残しておきます（遊ぶ人に配る必要はありません）。この確認は手元のCLIで行います

書き出したゲームには、工房のエンジンのライセンス表記（MIT License, © 2026 AI人狼ラボ）が CREDITS.md とゲームのクレジットに自動で入ります。消さないでください。ゲーム自体の権利は作者にあります。

販売サイトごとの規約・手数料・税の手続き、日本で個人が販売するときの表示義務などは、各サイトと公的な情報で確認してください（工房は代わりに判断しません）。

## 工房の中で作れる「素材だけの作品」

工房の中で作ったものは作者の自作（内蔵ジェネレーター製は MIT）なので、素材のまま配ったり売ったりできます。

- **キャラクター**: 「素材作り」画面の「キャラクター」で、体型・肌・髪・服・かぶり物・耳・しっぽ・マント・持ち物を選ぶと、歩くキャラクター（4方向×4コマ、64×64）ができます。「おまかせ」で偶然の組み合わせも。CLI: `pnpm rpg art character --project … --id fox-girl --name 狐の娘 [--from knight | --random 7] [--spec '{"ears":"cat"}']`
- **音楽**: 楽譜BGMは「楽譜BGM」画面の「WAVで書き出す」で、どこでも鳴らせる音声ファイルになります（ループする曲は、繰り返すと継ぎ目なくつながる長さ）。素材パックには WAV と工房の形式の両方が入ります
- **マップ**: 素材パックでマップを選ぶと、Tiled 形式（`.tmj`。無料のマップエディター Tiled や多くのゲームエンジンが読める）と1枚絵（`.png`）、使っているタイル画像が入ります。CLI: `pnpm rpg map export [<マップID>] --project …`。配れないタイル（AI生成・他サイト）を使うマップは入れられません
- **敵・モンスター**: 「素材作り」画面の「敵・モンスター」で、種類（17種）・体と差し色・飾り（王冠・翼・剣など）を選んで作れます。CLI: `pnpm rpg art monster --project … --id moon-slime --name 月のスライム --family slime --body "#8a7ae8" --extra crown`
- **タイル**: 「素材作り」画面の「タイル」で、内蔵の約170種のタイルから選び、模様・色・明るさ・画風を変えて自分のタイル集を作れます。動く水はコマごと、つながる床は9つの部品ごと入り、マップですぐ使えます。CLI: `pnpm rpg art tiles --project … --id night --name 夜の野原 --tiles "lib-tiles-field/grass:hue=200:light=-25,lib-tiles-field/water-anim-1" --style dusk`（`--list` で一覧）
- **顔グラフィック**: キャラクター作りで「顔グラフィックも作る」にすると、同じ見た目の顔（96×96、表情5つ: 普通・笑顔・怒り・悲しみ・驚き）が `face-ID` として一緒に登録されます。会話の顔（portrait）と表情（face 0〜4）に使えます。CLI: `pnpm rpg art portrait --project … --id fox-girl --character chr-fox-girl`（`--from knight` / `--random 7` でも）
- **戦闘背景**: 「素材作り」画面の「戦闘背景」で、見本（野原・夜の森・夕暮れの遺跡・雪原・砂漠）から空・山・地面・道・柱・木の色や数を変えて作れます（640×448）。CLI: `pnpm rpg art background --project … --id dusk --name 夕暮れの遺跡 --preset dusk-ruins [--seed 3] [--spec '{"trees":{"kind":"pine","color":"#2a4a3a","count":6}}']`
- **背景（ほか）**: 素材ライブラリ（内蔵ジェネレーター製）から取り込んだもの

## 素材だけを配る・売る（素材パック）

キャラクターだけ・音楽だけ・タイルだけ、のような素材集も作れます。工房の「素材」画面の「素材パックとして書き出す」、または:

```bash
pnpm rpg asset pack --project projects/<id> --title "森の村キャラクター素材集" --author "作者名" --kinds character,enemy --license cc-by-4.0 --out pack.zip
pnpm rpg asset pack --project projects/<id> --title "庭のマップ" --author "作者名" --maps garden,garden-house --license cc0 --out maps.zip
```

- 入れられるのは **自作と内蔵ジェネレーター製の素材だけ** です。他の人の素材（素材サイト・購入素材・AI生成）は、素材のまま配れないのが普通なので自動で外します。
- ライセンスは CC0（表記不要）・CC BY 4.0（作者名の表記）・独自の利用規約（素材集の販売でよく使われる形。ひな形あり）から選べます。
- README（収録内容・1コマの大きさ・使い方）・LICENSE.txt・CREDITS.md（出どころ）・pack.json（ツール用の一覧）が自動で付きます。タイルには各タイルの名前と通行の情報（`*.tiles.json`）も付きます。
- **見本画像 `preview.png`**: 収録した画像素材を番号つきで並べた1枚が付きます（キャラクター・敵・顔グラフィックは最初の1コマを見える部分だけ拡大、タイル・背景は全体）。番号は README の [番号] と同じです。販売ページの1枚目にそのまま使えます
