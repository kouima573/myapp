# 作ったものを公開・販売する

RPGシステム工房で作ったゲームや素材は、作者のものです。公開も販売も自由です。工房は「売れる状態に仕上げる」ところまでを手伝い、お金のやりとりは販売サイト（itch.io・BOOTH など）に任せます。

## ゲームを売る

1. **販売前チェック** — 工房の「検証」画面の「販売前チェック」、または `pnpm rpg release-check --project projects/<id>`。次をまとめて確かめます。
   - データの検証・自動テスト・エンディングまで遊べる自動テストがあるか
   - 書きかけの文章（TODO・（仮）・〇〇 など）・文章の点検
   - **素材の権利**: そのゲームを売ってよいか（自作・内蔵ジェネレーター製は可。他サイトの素材は取得元と記録から判定）
   - クレジット表記がそろっているか
2. 「不可」があれば直します。「要確認」は、規約を読んだうえで `assets.json` のその素材に `"commercial": true`（売ってよい）か `false` を書きます。**AI生成の画像**は、使った生成サービスの規約で決まります。
3. ゲームを書き出します（ブラウザ版の工房なら「ゲームZIPを作る」、手元なら `pnpm rpg build --project … --zip`）。
4. 販売サイトにアップロードします。ブラウザで遊べるZIPは、itch.io なら「HTML」のゲームとしてそのまま有料（または投げ銭）で出せます。

書き出したゲームには、工房のエンジンのライセンス表記（MIT License, © 2026 AI人狼ラボ）が CREDITS.md とゲームのクレジットに自動で入ります。消さないでください。ゲーム自体の権利は作者にあります。

販売サイトごとの規約・手数料・税の手続き、日本で個人が販売するときの表示義務などは、各サイトと公的な情報で確認してください（工房は代わりに判断しません）。

## 素材だけを配る・売る（素材パック）

キャラクターだけ・音楽だけ・タイルだけ、のような素材集も作れます。工房の「素材」画面の「素材パックとして書き出す」、または:

```bash
pnpm rpg asset pack --project projects/<id> --title "森の村キャラクター素材集" --author "作者名" --kinds character,enemy --license cc-by-4.0 --out pack.zip
```

- 入れられるのは **自作と内蔵ジェネレーター製の素材だけ** です。他の人の素材（素材サイト・購入素材・AI生成）は、素材のまま配れないのが普通なので自動で外します。
- ライセンスは CC0（表記不要）・CC BY 4.0（作者名の表記）・独自の利用規約（素材集の販売でよく使われる形。ひな形あり）から選べます。
- README（収録内容・1コマの大きさ・使い方）・LICENSE.txt・CREDITS.md（出どころ）・pack.json（ツール用の一覧）が自動で付きます。タイルには各タイルの名前と通行の情報（`*.tiles.json`）も付きます。
