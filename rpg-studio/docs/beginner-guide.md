# はじめてのRPG制作ガイド（AIと一緒に自由に始める）

専門用語やプログラミングがわからなくても、普段使っているAI（Codex や Claude Code）と一緒にオリジナルのゲームを形にできます。この工房の標準実行形式はRPGです。最初の土台には主人公と空のマップがありますが、物語・ジャンル・目的・戦闘をひな形が決めることはありません。ブラウザ版やチャット制作で足りない仕組みがあれば、ローカル版のCodex／Claude Codeでエンジンを拡張できます。

---

## 1. 専門用語のやさしい言い換え

| ツールやAIが使う言葉 | やさしい意味 |
| --- | --- |
| **プロジェクト** | 1本のゲーム全体が入ったフォルダのこと（この工房の標準形式はRPGです） |
| **フラグ (flags)** | ゲームが覚えている「ON / OFF のスイッチ」（例：村長と話したか） |
| **変数 (variables)** | 数字で覚えているもの（例：所持金、好感度、倒した数） |
| **アセット / 素材** | キャラクターや背景の絵、BGMや効果音のこと |
| **validate（検証）** | 行き先のない扉や誤字・設定ミスがないかの自動チェック |
| **test（テスト）** | AIがあなたの代わりにゲームを自動操作して動作確認すること |
| **build（ビルド）** | 作ったデータをブラウザで遊べる1つの完成品にまとめること |

---

## 2. 始め方を決める

決まった制作手順はありません。今あるものと今回やりたいことを、そのままAIに伝えてください。たとえば「一言の案を相談したい」「手元の台本のこの場面を作りたい」「まず触れる試作品がほしい」「既存ゲームの続きを直したい」のどれからでも始められます。資料を `IDEA.md` など決まった名前に移し替える必要もありません。

新しいRPGの技術的な土台が必要なときだけ、ローカル版で `pnpm rpg new my-rpg --title "作品名"` を使います。主人公と空マップはRPGランナーのための初期データです。発想シート `IDEA.md` は任意のメモで、書かずに始めても構いません。既存プロジェクトや試作品がある場合は、それを作り直さず続けます。見本や `--theme fantasy` なども、使いたいときだけ選びます。

この工房の標準実行形式はRPGです。別の形式が発想に合う場合も、RPG要素に言い換えず、そのまま希望を伝えてください。ブラウザ版・チャット版でできる範囲と、ローカル版で必要な拡張を説明し、実現方法を発想に合わせて考えます。

---

## 3. 必要なときだけ使える依頼例

下は書き換えて使える例です。どれかを選ぶ必要も、資料を先に作る必要もありません。

### 一言の案を、まず会話で広げたいとき
> 思いついた案は「眠ると、夢の町の配置が少しずつ現実に影響する」です。まだ制作資料や仕様書は作らず、まずこの案から考えられる遊び方をいくつか違う方向で出してください。まだ決めていないことは決定扱いしないでください。

### 自分の作り方・AIとの進め方が決まっているとき
> 私は自分のやり方で制作したいです。次の進め方・作業の順序・AIに頼みたい範囲を守ってください。あなたの標準的な工程や、工房にある機能に合わせて作業を組み替えないでください。進め方を変える必要があるときは、先に理由と選択肢を示してください。
>
> 私の進め方：ここに自由に書く

### 手元の資料や途中の場面から直接始めたいとき
> 添付した台本の「第3章・時計塔の場面」だけ、会話できる形にしてください。既存の設定を `IDEA.md` に移したり、資料全体を要約したりせず、この場面に必要なファイルだけ変更してください。過去の章やプロローグは追加しないでください。

### まず試作品を触って決めたいとき
> このルールを試せる小さな試作品を作ってください。仕様書や本編はまだ作らず、指定したルールだけ触って確かめられる形にしてください。試作品の後で方向を変える可能性があります。

### 相談・レビューだけしたいとき
> この案の弱いところと、意図が伝わりにくそうなところをレビューしてください。ファイルは変更しないでください。必要なら複数の改善案を示し、どれを採用するかは決めないでください。

### 見本を使いたいとき
> 見本ゲームをベースに、主人公が魔法使いで、森の奥の塔を目指す短いRPGに作り変えてください。頼んでいない設定や機能は追加しないでください。見本を使わず新しく始める方法もあります。

### マップやイベントを増やしたいとき
> 今の村の北に「古い図書館」のマップを追加して、本棚を調べると世界の歴史が読めるイベントを1つ入れてください。

### 絵や音を選びたいとき
> 主人公とスライムの絵を変えたいです。番号つきの見本画像を出してもらえますか？ BGMも聴いて選べるURLを出してほしいです。

### 敵の強さやバランスを直したいとき
> 遊んでみたら最初の敵が強すぎて勝てませんでした。主人公のHPを少し上げて、回復アイテムを1個持った状態から始まるように直してください。

### エラーが出て動かなくなったとき
> 何かおかしくなってゲームが開けません。今の状態でチェック（validate と test）を実行して、何が原因かやさしい言葉で教えてください。
