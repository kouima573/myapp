# はじめてのRPG制作ガイド（AIと一緒に作る手順）

専門用語やプログラミングがわからなくても、普段使っているAI（Codex や Claude Code）に話しかけるだけでオリジナルのRPGを作れます。工房の画面を開く必要もありません。

---

## 1. 専門用語のやさしい言い換え

| ツールやAIが使う言葉 | やさしい意味 |
| --- | --- |
| **プロジェクト** | 1本のRPGゲーム全体が入ったフォルダのこと |
| **フラグ (flags)** | ゲームが覚えている「ON / OFF のスイッチ」（例：村長と話したか） |
| **変数 (variables)** | 数字で覚えているもの（例：所持金、好感度、倒した数） |
| **アセット / 素材** | キャラクターや背景の絵、BGMや効果音のこと |
| **validate（検証）** | 行き先のない扉や誤字・設定ミスがないかの自動チェック |
| **test（テスト）** | AIがあなたの代わりにゲームを自動操作して動作確認すること |
| **build（ビルド）** | 作ったデータをブラウザで遊べる1つの完成品にまとめること |

---

## 2. 最初の一歩（5分チュートリアル）

1. **まずは見本を遊ぶ**: 公開サイトやローカルで `sample-rpg` を少しだけ遊んで、どんな動きをするか体験します。
2. **新しいゲームの箱を作る**: AIに「`my-rpg` という名前で新しいRPGを作りたい」と伝えます（`rpg new my-rpg --theme fantasy`）。
3. **一言だけアイデアを伝える**: 下の「そのまま送れる質問テンプレート」から1つ選んで、AIに話しかけます。

---

## 3. そのままコピペしてAIに送れる質問テンプレート

### 企画がまだぼんやりしているとき
> RPGシステム工房で新しいゲームを作りたいです。まだアイデアがぼんやりしているので、私に3つずつ質問しながら、一緒に企画（IDEA.md）と最初の村を作ってくれますか？

### 見本をベースに改造したいとき
> 見本ゲーム（sample-rpg）をベースに、主人公が魔法使いで、森の奥の塔を目指す短いRPGに作り変えたいです。まず何を決めるべきか教えてください。

### マップやイベントを増やしたいとき
> 今の村の北に「古い図書館」のマップを追加して、本棚を調べると世界の歴史が読めるイベントを1つ入れてください。

### 絵や音を選びたいとき
> 主人公とスライムの絵を変えたいです。番号つきの見本画像を出してもらえますか？ BGMも聴いて選べるURLを出してほしいです。

### 敵の強さやバランスを直したいとき
> 遊んでみたら最初の敵が強すぎて勝てませんでした。主人公のHPを少し上げて、回復アイテムを1個持った状態から始まるように直してください。

### エラーが出て動かなくなったとき
> 何かおかしくなってゲームが開けません。今の状態でチェック（validate と test）を実行して、何が原因かやさしい言葉で教えてください。
