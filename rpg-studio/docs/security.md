# ローカルサーバーの安全性

`pnpm studio` は選んだ**1つのプロジェクトフォルダ**だけを扱うローカルサービスを起動します（`packages/local-server/src/server.ts`）。

| 層 | 内容 |
| --- | --- |
| 待受 | `127.0.0.1` のみ（LANに公開しない） |
| Host | `127.0.0.1:<port>` と `localhost:<port>` 以外は403（DNSリバインディング対策） |
| Origin | 付いている場合は同じ2つのOriginのみ。更新系はOrigin必須。CORSヘッダーは一切返さない |
| トークン | 起動ごとに32バイトの乱数。配信するHTMLの `<meta>` にだけ埋め込み、全API（読込・保存・監視・ビルド・テスト・素材）で `x-rpg-studio-token` を検査。URL・ログ・ファイルには出さない |
| パス | プロジェクト相対・正規化済み（`..`・絶対パス・`\`・ドット始まりの要素を拒否）。すべての要素を `lstat` してシンボリックリンク／ジャンクションを拒否し、最終ファイルは `O_NOFOLLOW` で開く（POSIX） |
| 種類・量 | 読込は `.json .ts .md .png .ogg .mp3 .wav`、工房からの保存はテキスト(`.json .ts .md`)のみ・4MB以下。不正なJSONは保存しない。新規ファイル作成は不可 |
| 競合 | 保存は「読込時のSHA-256」と一致する場合だけ。不一致なら409と最新内容を返し、工房が双方を表示して選ばせる |
| 書込 | ファイル単位で直列化し、同じディレクトリの一時ファイルに `fsync` してから `rename` で置換 |
| 操作 | 固定の処理（読込・保存・ビルド・テスト）だけ。任意のコマンド、スクリプトパス、起動オプションは受け取らない |
| 応答 | `X-Content-Type-Options: nosniff`、UIにCSP（`frame-ancestors 'none'`）、`no-store` |

`packages/local-server/src/server.test.ts` で Host／Origin／トークン拒否、CORSなし、パストラバーサル・シンボリックリンク拒否、古いハッシュの409（ディスク不変）、不正JSON・バイナリ書込・新規ファイルの拒否、コマンドAPIの不在を確認しています。

## 既知の限界

- SHA-256照合は「工房が読んだ後に変わったか」を検出しますが、照合とrenameの間の極めて短い時間の外部書込みまでは防げません。**同じファイルを工房とエージェントで同時に編集しない**運用にしてください（エージェントに渡す前に工房の保存が終わっていること＝上部が「保存済み」を確認）。
- システムTypeScriptは信頼されたコードとして実行されます。他人のプロジェクトは `git diff` を確認してから開いてください。
- Windowsのジャンクション拒否と、置換失敗時に元ファイルが残ることは**Windows実機で未検証**です。
